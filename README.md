# Loquela

A small, self-hosted Latin learning app — a personal Duolingo for Latin.

Loquela is a single-user web app built with Node.js and EJS. It offers three
independent Latin courses and stores progress in a single local file. No
accounts, no database, no cloud. Just you and the language.

The name comes from the Latin word *loquēla* — "talk, chatter, everyday
speech" — which is exactly the point: Loquela focuses on Latin you can
actually use, not just the Latin of textbooks.

---

## What it does

Loquela gives you three courses:

- **Latinum Fundamentum** — absolute beginner Latin. Greetings, numbers,
  colors, family. A gentle introduction to the app and to the language.
- **Sermo Cotidianus** — everyday Latin. Weather, routine, transportation,
  school, food, small talk. This is the heart of the app: the Latin that
  most traditional courses never teach you.
- **Latinum Peritum** — advanced Latin. Short, dense sentences, classical
  quotes, complex syntax. For when you want to read the real thing.

Each course is a vertical path of short lessons. Lessons are sequences of
small exercises with instant feedback — the same flow you already know from
Duolingo, but in Latin and without the streak guilt.

The app is fully local. Everything — the courses, the exercises, your
progress — lives as plain files on your machine.

---

## Features

- Three independent courses, each with its own lesson map.
- Six exercise types: multiple choice, translation, matching, word order,
  fill-in-the-blank, and true/false.
- Instant feedback after every exercise, with short explanations.
- XP and streaks tracked in a single `progress.json` file.
- Every time you open a lesson, exercises and answers are shuffled on the
  fly, so you never see the same order twice.
- Progress is linear: complete a lesson to unlock the next one.
- Delete `progress.json` and everything resets. That's the whole save system.

## How to use it

1. Open the app. You'll see three course cards.
2. Pick a course. You'll see its lesson map.
3. Click the first unlocked lesson.
4. Work through the exercises. Each one gives immediate feedback.
5. Finish the lesson to earn XP and unlock the next one.
6. Come back tomorrow. Your streak updates.

That's the entire interface. There are no menus to explore, no settings
screens, no onboarding flow.

## Adding or editing courses

Courses live in the `courses/` folder at the project root, completely
separate from the application code. Each course is a folder containing:

```
courses/
└── my-course/
    ├── course.json
    └── lessons/
        ├── 01-first-lesson.json
        ├── 02-second-lesson.json
        └── ...
```

To add a new course, drop a folder there with a valid `course.json` and at
least one lesson file. Restart the app and the new course appears on the
home screen automatically.

To edit an existing course, just change the JSON files and restart. The app
validates every course and lesson on startup and will refuse to load
anything malformed — you'll see a clear error in the console pointing to
the broken file.

For the exact format of these files, see:

- `docs/COURSE_SCHEMA.md` — structure of `course.json`.
- `docs/LESSON_SCHEMA.md` — structure of lesson files and all exercise types.
- `docs/ADDING_LESSONS.md` — step-by-step guide with examples.

---

## Resetting progress

Delete `progress.json` at the project root. Done. Next time you open the
app, all courses are locked again and your XP is zero.

The file is safe to edit by hand if you ever want to jump ahead or restore
a course state. Its schema is documented in `docs/ARCHITECTURE.md`.

## Philosophy

Loquela is a personal tool, not a product. It's designed for a single
person who wants to keep a Latin diary and needs the language of daily
life, not the language of Caesar. Everything is optimized for that:
plain files, no sync, no accounts, no ceremony. Add lessons as you go,
delete progress when you want, break things without fear.

If you're using it, you're already using it correctly.
